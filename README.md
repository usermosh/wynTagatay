# Lunaire Boutique Hotel Resort

A static multi-page luxury hotel website for a boutique resort concept in Tagaytay, Philippines. The project presents a premium nightlife-inspired brand experience centered around moonlight, quiet luxury, wellness, and hospitality.

## Overview

This website is designed as a polished front-end experience for a boutique hotel/resort brand called Lunaire. It includes:

- A landing page for the resort experience
- Room and suite listings
- Dining and wellness sections
- Entertainment and leisure pages
- About/story page
- Contact/booking experience
- Interactive booking flow with date selection and package pricing

## Brand concept

Lunaire is positioned as a 4-star boutique resort inspired by the calm elegance and atmosphere of moonlit luxury. The visual design uses a quiet, premium palette with dark tones, warm gold accents, and a soothing highland resort feel.

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- No framework or backend required

## How to run

Because this is a static website, you can run it in either of these ways:

1. Open the file directly in a browser:
   - Double-click `index.html`

2. Or run a local web server from the project folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Notes

- The site is front-end only and does not connect to a real booking backend.
- Contact and booking submissions are handled as local demo validation rather than a live database or API.
- Images and brand visuals are stored in the `img` folder.

## Customization ideas

- Update hotel details, pricing, and room names in the HTML and JS files.
- Adjust colors, spacing, and typography in `tokens.css` and `main.css`.
- Replace placeholder imagery in `img/` with real resort photography.
- Connect the booking form and inquiry form to a backend service later.
