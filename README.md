# Lunaire Hotel Resort Website Concept

## Project Overview

**Lunaire** is a fictional four-star luxury boutique hotel resort
concept located in **Tagaytay, Philippines**. The website is inspired by
the elegant, mysterious, moonlit atmosphere associated with the Korean
series *Hotel Del Luna*, while developing an original visual identity,
brand story, and guest experience.

**Tagline:**\
\> Where Memories Shine Under the Moonlight.

Lunaire is designed as a serene, high-end sanctuary where guests can
step away from everyday pressures, rest, reflect, reconnect, celebrate
meaningful moments, and create memories---even if they visit only once.

> **Important:** All room types, prices, facilities, capacities,
> policies, and services in this document are fictional or conceptual
> samples for a website project. They must not be presented as verified
> real-world hotel information.

## Website Goals

The website should:

1.  Communicate Lunaire's luxury boutique identity.
2.  Make the property feel peaceful, cinematic, and welcoming.
3.  Showcase rooms, dining, wellness, experiences, and events.
4.  Guide visitors toward booking or submitting a reservation request.
5.  Present conceptual hotel information clearly and transparently.
6.  Use emotionally resonant copy without becoming overly dramatic.
7.  Make navigation intuitive on desktop and mobile.
8.  Encourage guests to explore the property before reserving.
9.  Build trust through clear policies, contact details, and transparent
    pricing.
10. Create a consistent visual experience across every page.

# Global Website Direction

## Visual Style

The website should feel like a luxury editorial experience with subtle
nighttime mystery.

### Recommended Color Palette

-   Midnight Navy
-   Deep Charcoal
-   Champagne Gold
-   Ivory / Warm White
-   Dusty Lavender
-   Muted Mauve
-   Soft Silver accents used sparingly

### Typography

**Headings:**

-   Playfair Display
-   Cormorant Garamond
-   Libre Baskerville

**Body Text and Interface:**

-   Inter
-   Montserrat
-   Lato

### Image Direction

Use imagery featuring:

-   Moonlit hotel exteriors
-   Warm room lighting
-   Elegant guest rooms
-   Tagaytay scenery
-   Foggy or atmospheric landscapes
-   Moonlit pool reflections
-   Refined dining settings
-   Spa details
-   Couples and families enjoying calm moments
-   Garden paths
-   Candlelit or softly illuminated event spaces
-   Architectural details
-   Night skies and stargazing

### Design Principles

-   Use generous whitespace.
-   Avoid excessive animation.
-   Use slow, subtle transitions.
-   Keep gold accents restrained.
-   Prioritize readability and accessibility.
-   Use strong contrast for text.
-   Avoid visual clutter.
-   Maintain a calm, premium rhythm.
-   Make booking actions visible without feeling aggressive.
-   Ensure all interactive elements are keyboard-accessible.
-   Optimize all images for performance.
-   Design mobile-first.

## Booking FAQ

### Can I change my dates?

In a real implementation, date changes would depend on availability and
the applicable rate conditions. In this prototype, users can return to
the date-selection step.

### Can I add a package after selecting a room?

Yes. The interface should allow guests to add or remove conceptual
packages before reviewing the reservation.

### Can I request a celebration setup?

Yes. Guests can select an occasion and describe their preferred
arrangement. Requests should be marked as subject to confirmation.

### Does submitting the form confirm a reservation?

No. In the prototype, submitting the form creates a simulated request
only.

### Can I make special requests?

Yes. Include a special requests field and an accessibility needs field.
Avoid promising that every request can be fulfilled.

# User Experience Requirements

## Navigation

-   Keep the main navigation simple.
-   Include a visible booking button.
-   Use breadcrumbs on inner pages.
-   Provide a mobile menu.
-   Keep page titles clear.
-   Use consistent button labels.

## Accessibility

-   Maintain readable color contrast.
-   Add alt text to images.
-   Use descriptive link labels.
-   Support keyboard navigation.
-   Include visible focus states.
-   Avoid relying on color alone.
-   Provide form labels and helpful error messages.
-   Ensure the booking process works on mobile.

## Performance

-   Compress images.
-   Use responsive image sizes.
-   Avoid unnecessary video backgrounds.
-   Lazy-load below-the-fold imagery.
-   Minimize heavy animations.
-   Optimize font loading.
-   Test on slower mobile connections.

## Responsive Layout

The website should work across:

-   Mobile phones
-   Tablets
-   Laptops
-   Desktop monitors

The booking page should use a single-column layout on mobile and a
two-column layout with a sticky summary on desktop.

# Final Creative Direction

Lunaire should feel like entering a quiet story after sunset.

The website should not simply sell rooms. It should communicate the
possibility of rest, connection, reflection, celebration, and renewal.
The guest journey should move naturally from curiosity to emotional
connection, then from exploration to a clear and reassuring reservation
request.

Every page should support the central idea:

> **At Lunaire, even a single night can become a memory that shines long
> after the moon has set.**
